# Watch Together

Простой сайт для совместного просмотра видео.

## Запуск локально

```bash
npm install
npm start
```

Откройте:

http://localhost:3000

## Что поддерживается

- комнаты по ссылке;
- общий чат через Socket.IO;
- RUTUBE с синхронизацией play/pause/seek;
- YouTube и другие ссылки пробуются через iframe;
- адаптивный интерфейс для телефона и компьютера.

## Важно

Не каждый видеосайт разрешает открывать свои страницы внутри iframe. Также полная синхронизация зависит от наличия API управления плеером.

Для Render:
- Build Command: `npm install`
- Start Command: `npm start`
